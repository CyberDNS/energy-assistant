# Nornwatt branding

Logo: three threads (past, present, future, after the Norns) running into one lightning bolt.

| File | Use |
|---|---|
| `nornwatt-icon.svg`, `nornwatt-icon-{128,256,512}.png` | App / add-on icon (navy rounded square) |
| `nornwatt-mark-on-dark.svg`, `nornwatt-mark-on-light.svg` (+ 512 px PNG) | Mark alone, two colours |
| `nornwatt-mark-mono-dark.svg`, `nornwatt-mark-mono-white.svg` | Mark alone, one colour |
| `nornwatt-logo-on-dark.svg`, `nornwatt-logo-on-light.svg` (+ PNG, 240 px high) | Mark with the name |
| `nornwatt-logo-mono-dark.svg`, `nornwatt-logo-mono-white.svg` | Mark with the name, one colour |

PNGs have a transparent background (except the icon).

## Colours

| Colour | Hex | Use |
|---|---|---|
| Night blue | `#101B33` | Background, threads and name on light |
| Amber | `#F5A623` | Bolt on dark backgrounds |
| Deep amber | `#B86E00` | Bolt on light backgrounds |
| White | `#FFFFFF` | Threads and name on dark |

## Typeface

The name is set in Josefin Sans Bold capitals with wide letter spacing (SIL Open Font License 1.1), converted to
outlines in the logo files, so the font does not need to be installed.
